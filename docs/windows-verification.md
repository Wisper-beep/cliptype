# v1.0.0 Windows 验证记录（历史）

vNext 结果单独记录在 `VNEXT_TEST_RESULTS.md`。

- 基础测试：14 项通过，包含 Win32 INPUT 内存布局、Unicode 按键、代理对、组合字符、换行、控制字符、按键释放、设置校验和取消。
- 原生集成测试：共 23 项通过，包含真实 SendInput 输入中文、英文、表情和换行，选区替换，中途取消，Shift / Ctrl 释放，普通 Ctrl + V 粘贴以及控件焦点改变时停止。
- 窗口构造及释放：主窗口和选择窗口均通过检查；修复了 NumericUpDown 初始化范围、重复 Dispose 和高 DPI 下的裁切。
- 桌面端到端：通过全局 Ctrl + Alt + V 呼出选择面板，选择模拟输入后返回本地试输入框，在原选区完整写入「ClipType 测试：中文 English 🙂」，状态显示 24 个输入单元完成。
- 高 DPI：人工检查主界面与选择面板截图，文字、按钮和设置均可见。
- 浏览器：已提供本地测试页；自动化工具因无法可靠确认当前网址而终止，未完成浏览器输入框的实测。聊天软件未实测。

真实输入集成测试需要与目标窗口相同的桌面访问权限。受限沙箱拒绝 SendInput 时，应在正常的交互式 Windows 会话中运行测试。
