# 隐私与权限

ClipType 不向任何服务器发送文字、网址、浏览记录或使用数据，也没有分析、广告或外部脚本。

| 权限 | 用途 |
| --- | --- |
| activeTab | 点击扩展图标或调用快捷键时，临时访问当前标签页，定位用户选中的输入框 |
| scripting | 把本地打包的输入逻辑注入当前网页 |
| clipboardRead | 打开面板时及点击读取按钮时，读取剪贴板中的纯文本 |
| storage | 只保存速度、延迟、换行、节奏停顿和快捷按钮偏好 |

发行版没有 host_permissions，也不会在所有网站上自动注入脚本。它不轮询剪贴板、不保存剪贴板历史、不记录表单内容或输入结果。

文字只在打开的面板和当前输入任务的内存中使用。关闭面板后文字不会写入本地存储；输入任务结束后不保留任务引用。任务内容会按用户要求写入目标网页，之后由该网站自己的数据处理规则管理。
